概要

DuckDB は SQLite のように単一ファイル・サーバ不要で動きながら、 列指向ストレージとベクトル化実行エンジンを持つ OLAP 向けのデータベース。 手元の CSV / JSON / Parquet をそのままテーブルのように SQL で扱えるので、 「集計のためだけに DWH へ上げる」手間を省ける。

  • SQLite の OLAP 版
    • 分析用途に振り切った設計 (列指向 + ベクトル化実行)
    • Notebook 系のライブラリの内部でも使われている
      • PyGWalker / dbt-duckdb など
  • 様々な種類のデータを読み込める
    • CSV / JSON / Parquet / S3 上のファイル
  • インストールが軽い -- 依存なしの単一バイナリ

コード例

ファイルを CREATE TABLE で取り込まなくてよい。 read_json / read_csv にパスを渡せば、 その場でテーブルとして SELECT できる。

入力ファイル

users.json 
[
  {
    "id": 1,
    "name": "Alice",
    "age": 30
  },
  {
    "id": 2,
    "name": "Bob",
    "age": 25
  }
]

読み込み

D SELECT * FROM read_json('users.json');
┌───────┬─────────┬───────┐
│  id   │  name   │  age  │
│ int64 │ varchar │ int64 │
├───────┼─────────┼───────┤
│   1   │ Alice   │   30  │
│   2   │ Bob     │   25  │
└───────┴─────────┴───────┘

実践

インストール

単一バイナリなのでパッケージマネージャから入れて終わり。

install.sh 
$ brew install duckdb
$ duckdb # 引数なしならインメモリDBで起動

集計クエリ

read_csv はスキーマを推論するので、型指定なしでいきなり GROUP BY できる。結果は CLI が ASCII 罫線で整形して返す。 

D SELECT dept, count(*) AS cnt, avg(salary)::INT AS avg_salary
D FROM read_csv('employees.csv')
D GROUP BY dept ORDER BY cnt DESC;
┌─────────────┬───────┬────────────┐
│    dept     │  cnt  │ avg_salary │
│   varchar   │ int64 │   int32    │
├─────────────┼───────┼────────────┤
│ Engineering │    42 │     720000 │
│ Sales       │    18 │     540000 │
│ Design      │     7 │     610000 │
