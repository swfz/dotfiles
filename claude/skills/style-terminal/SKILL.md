# style-terminal

エンジニア向けの **ターミナルウィンドウ風ダークスタイル** (ドキュメントは白背景のライトテーマにも切り替え可) で、スライドデッキまたは縦スクロールの
HTML 資料を、外部リソースに依存しない単一 HTML として生成する。Artifact 公開・ローカル閲覧の両方で使える。

## モード判定 (最初にやる)

| モード | 用途 | テンプレート |
|--------|------|--------------|
| **スライド** | LT・プレゼン・発表資料。1画面ずつ見せる | `assets/slide.html` |
| **ドキュメント** | 読み物・共有資料・設計ドキュメント。縦スクロールで読む | `assets/document.html` |

「発表する」ならスライド、「読んでもらう」ならドキュメント。迷ったら用途を確認する。

## デザインの要点 (両モード共通のビジュアル言語)

| 要素 | 仕様 |
|------|------|
| ウィンドウ枠 | **ターミナルウィンドウ**化。信号機ドット + `swfz@mac: ~/talks/… — zsh` のタイトルバー、角丸・ドロップシャドウ |
| 背景 | ページ地は `#12181f` + ビネット、ウィンドウ地は `#2b3646`。微かな**スキャンライン** |
| フォント | 等幅 (`ui-monospace` 系)。日本語はシステムのゴシックにフォールバック |
| 見出し | 先頭にピンクの `❯` シェブロン (`--accent #e23f7a`) + 白テキスト |
| 箇条書き | **`tree` コマンド風の結線**。縦スパイン `│` + エルボー `├`/`└` を CSS 罫線で描画。深いほど小さく淡く |
| コード | **ファイル名タブ**(`● users.json`)付き。中身にフィットする幅。多色シンタックス |
| 端末出力 | DuckDB CLI 風の **ASCII 罫線テーブル** を `<pre class="term">` に生貼り。行頭 `D`/`$`/`❯` は緑 |
| シンタックス色 | キーワード=ピンク `.kw` / 関数・キー=青 `.fn` / 文字列=緑 `.str` / 数値=琥珀 `.num` / コメント=灰斜体 `.com` |
| 2カラム | `.cols` で左右分割。左コード / 右出力などの対比に |
| 画像 | **白背景ボックス**に収める (`.figure img`)。下にシアン下線リンクの出典 |
| ステータスライン | 下端に **powerline / tmux 風ステータスライン** (`NORMAL` モード → `git:main` → ファイル名 → `utf-8` → 位置情報)。矢印は Nerd Font ではなく CSS clip-path で描画 |
| タイトル | **ブート風プロンプト** (`❯ ./present.sh …`) + 大きな等幅タイトル + **点滅カーソル** |

### モード固有

- **スライド**: **16:9 レターボックス**。container query (cqw/cqh) でウィンドウ幅に追従。1スライド = 1ウィンドウ。ステータスラインにページ番号 `N/総数`
- **ドキュメント**: 縦スクロールの通常フロー。**ドキュメント全体で1つのウィンドウ**。冒頭にタイトルブロック + `tree` 風の目次を置き、章 (h2単位) は `<section class="sec">` として**破線だけで区切る** (章ごとにウィンドウは作らない)。ステータスラインは `position: sticky` で画面下に張り付き、`.seg--count` が vim 風のスクロール位置 (`Top` / `45%` / `Bot`) を出す。ヘッダーバー (`.win-bar`) も `position: sticky` で画面上部に固定され、タイトルブロックが画面外に出ると**パス表示の代わりに「タイトル ❯ 現在の章見出し」(`.win-doc-title`) を中央に表示**する (scrollspy でスクロールに追従。最初の章より手前ではサブタイトル。手書きすれば任意の固定文字列にできる)
- **ライトテーマ (ドキュメントのみ)**: `<div class="doc doc--light">` と class を足すだけで白基調に切り替わる。`body:has(.doc--light)` で配色変数を一括上書きしている。読み手もヘッダーバー右端の **`.theme-toggle` ボタンでいつでも切り替えられる** (選択は localStorage に保持)。class は初期テーマの指定 — 印刷したり明るい環境で読む資料なら `doc--light` 始まりを提案する

色・レイアウトの実体はすべてテンプレート HTML の `:root` 変数と CSS にある。**まず該当モードのテンプレートを読むこと。**
ダークの配色変数は両テンプレートで同一 (document.html はライトテーマ用に変数が少し多い)。**色を調整するときは必ず両方のテンプレートを揃えて変える。**

## ワークフロー

1. **モードを判定し、該当テンプレートを読む。** どちらも全コンポーネントを含む動くリファレンス (DuckDB 例) を兼ねる。
2. **内容を差し替える。**
   - スライド: 1トピック = 1 `<section class="slide">` → `<div class="slide-inner">` の中に `.win-bar` / `.win-body` / `.status` の3段。ページ番号は `.status` の `.seg--count` 内 `<span class="pageno">N</span>/総数` を更新 (タイトルは `1`)。
   - ドキュメント: 全体を `<div class="doc">` (中央寄せ・最大幅900px。コードやテーブルが多いなら `doc--wide` を足して1200px、任意幅は `--doc-w` で指定) → `<div class="doc-win">` (`.win-bar` / `.win-body` / `.status` の3段) で包む。`.win-body` の中にタイトルブロック + 目次 `<ul class="tree toc">` を置き、続けて章を `<section class="sec" id="sec-N">` として並べる。目次の `<a>` は各章の `id` へのページ内リンク。`.seg--count` は末尾の JS が自動更新するので触らない。ライトにするなら `.doc` に `doc--light` を足す。
   - `.win-bar` のパス表示と `.status` の `git:` ブランチ・ファイル名・モードは**テーマに合わせて書き換える**と世界観が締まる。
3. **画像は data: URI で埋め込む** (Artifact は外部URL・CDN・フォント読み込みを CSP でブロックする)。
   - ローカル画像 → base64 化して `<img src="data:image/png;base64,...">`。
4. **出力**
   - **Artifact 公開** (既定): テンプレートは doctype/html/head/body を持たない**フラグメント**なので、そのまま Artifact ツールに渡せる。**先に `artifact-design` スキルを読む** (Artifact ツールの要件)。`favicon` は端末系の絵文字 (例 `🖥️` `⚡`) を渡す。
   - **ローカル HTML** で欲しい場合はファイルパスを渡す。WSL なので `file:///...` と `file://wsl.localhost/Ubuntu/...` の両方を返す。
5. **操作確認**: スライドは `← → / Space / PageUp・Down` で移動、ドキュメントは目次リンクで章に飛べる・スクロールでステータスラインの位置表示が変わる・ヘッダーバーが上部に固定され大枠タイトルが出る・`.theme-toggle` でテーマが切り替わる。Artifact 公開後や画面確認が要る場合は Playwright で最低限の表示・操作を確認する。

## コンポーネント早見表

すべて各テンプレートに実例がある。クラス名だけ抜粋:

- **ウィンドウ枠**: (スライド `.slide-inner` / ドキュメント `.doc-win`) に `.win-bar`(信号機ドット `.dot.r/.y/.g` + `.win-title`) / `.win-body` / `.status` の3段。ドキュメントの `.win-bar` はさらに `.win-doc-title`(sticky 時の「タイトル ❯ 現在の章見出し」・空のままなら JS が自動更新) + `.theme-toggle`(テーマ切り替えボタン・ラベルは JS が入れる) を持つ
- **タイトル**: `.win-body` に `.boot`(プロンプト行) + `.title-main`(+`.cursor` 点滅) + `.title-sub`
- **見出し**: `<h2 class="head">…</h2>` (`❯` は ::before で自動付与)。ドキュメントの小見出しは `<h3 class="subhead">…</h3>` (`❯❯` 淡色)
- **章** (ドキュメントのみ): `<section class="sec" id="sec-N">` を `.win-body` 直下に並べる (2つ目以降は破線で自動区切り)
- **目次** (ドキュメントのみ): `<ul class="tree toc">` にページ内リンク `<a href="#sec-N">`
- **ツリー箇条書き**: `<ul class="tree">` に `<li>` をネスト。結線は CSS 自動。コード語は `.kw`/`.fn`/`.str`/`.num`/`.com`/`.dim` で着色
- **コード**: `.code-wrap` に `.code-tab`(ファイル名) + `<pre class="code">`。中は色 span で装飾
- **端末出力**: `<pre class="term">` に ASCII テーブルを生貼り。プロンプト行は `<span class="p">`
- **2カラム**: `<div class="cols">` に子2つ
- **画像**: `<figure class="figure">` → `<img>` + `<figcaption>` (出典は `<a class="link">`)
- **ステータスライン**: `.status` に `.seg--mode` / `.seg--branch` / `.seg--file` / `.seg--spring`(伸縮) / `.seg--info` / `.seg--count`

## 注意

- **等幅フォントが世界観の核**。日本語も等幅系にフォールバックさせる (テンプレの `--mono` を触らない)。
- スライドはテキスト量が多いと 16:9 からはみ出る。`cqw`/`cqh` 基準なので**1スライドの情報量を絞る**のが正解 (元スタイルも余白が多い)。長文になるならドキュメントモードを提案する。
- ドキュメントは長文に耐えるが、**1章を長くしすぎない**。h2 (`.sec`) で適度に区切り、目次から飛べるようにする。
- 端末出力の ASCII テーブルは**実際のコマンド出力を貼る**のが最も本物らしい。整形しすぎない。
- powerline 矢印・信号機ドットは **CSS だけで描画**している (Nerd Font に依存しない) ので Artifact でもそのまま出る。
- グラフや集計の可視化が主目的なら、このスキルではなく `drilldown-report` / `timeseries-report` を使う。
